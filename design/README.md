# Design reference

These four files are the approved mockups for the site, exported from a design canvas.

- `Main.dc.html`: homepage
- `Painting.dc.html`: painting (product) page with enquiry form
- `Features.dc.html`: features page (in homes, press, exhibitions and events)
- `About.dc.html`: My story page

They use a custom component format (`<x-dc>`, `<sc-for>`, `{{holes}}`) and will not render on their own. Read them as a precise spec: all colours, sizes, spacing, font weights and layout are in the inline styles. Ignore the wrapper tags and the script block.

The coloured gradient blocks are placeholders for photographs. They are not part of the design.
Text in [square brackets] is placeholder copy to be replaced with real content in the Shopify admin.
